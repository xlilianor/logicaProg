Manipulação de Arquivos em Python

Disciplina: Lógica de Programação

Assunto: Manipulação de arquivos em Python

1. Por que utilizar arquivos?

Até agora, os dados utilizados pelos nossos programas normalmente ficam armazenados em variáveis.

nome = input("Digite seu nome: ")
print(nome)

Enquanto o programa está executando, o valor de nome está disponível. Porém, quando o programa termina, esse valor é perdido.

Arquivos permitem armazenar informações de forma permanente.

Eles podem guardar nomes de alunos, notas, produtos, configurações, resultados de pesquisas, registros de acesso e relatórios.

2. Preparando a pasta da atividade

  • Crie uma pasta chamada aula_arquivos.
  • Dentro dela, crie um arquivo Python chamado arquivos.py.
  • Mantenha inicialmente todos os arquivos utilizados na mesma pasta do programa.

3. Criando nosso primeiro arquivo

Digite e execute:

arquivo = open("mensagem.txt", "w")

arquivo.write("Olá, mundo!")

arquivo.close()

Depois da execução, abra a pasta do projeto e localize mensagem.txt.

Observe: o arquivo não existia antes da execução. O Python criou o arquivo para nós.

Pergunta

O que foi armazenado dentro de mensagem.txt?

4. Entendendo open()

A função open() permite abrir ou criar arquivos.

open("mensagem.txt", "w")
ParteSignificado
"mensagem.txt"nome do arquivo
"w"modo de abertura

Principais modos

ModoNomeComportamento
"r"readLê um arquivo existente
"w"writeEscreve e substitui o conteúdo anterior
"a"appendAcrescenta conteúdo ao final
"x"createCria um arquivo novo; gera erro se ele já existir

5. Cuidado com o modo "w"

Modifique o programa:

arquivo = open("mensagem.txt", "w")

arquivo.write("Segunda mensagem")

arquivo.close()

Execute novamente e abra mensagem.txt.

Pergunta

O que aconteceu com a mensagem anterior?

Atenção: o modo "w" apaga o conteúdo anterior do arquivo antes de escrever o novo conteúdo.

6. Acrescentando conteúdo com "a"

Agora utilize:

arquivo = open("mensagem.txt", "a")

arquivo.write("Nova mensagem")

arquivo.close()

Execute várias vezes.

Pergunta

O conteúdo anterior foi apagado?

O modo "a" acrescenta informações ao final do arquivo.

7. Quebra de linha com \n

Sem uma quebra de linha, as mensagens podem ficar uma ao lado da outra.

arquivo = open("mensagem.txt", "a")

arquivo.write("Nova mensagem\n")

arquivo.close()

O símbolo \n representa uma quebra de linha.

Teste:

arquivo = open("mensagem.txt", "w")

arquivo.write("João\n")
arquivo.write("Maria\n")
arquivo.write("Carlos\n")

arquivo.close()

Resultado esperado em mensagem.txt:

João
Maria
Carlos

8. A forma recomendada: with

Em Python, podemos utilizar:

with open("mensagem.txt", "w") as arquivo:
    arquivo.write("Olá!")

Neste caso, não precisamos executar arquivo.close().

A partir de agora, utilizaremos with.

O Python fecha o arquivo automaticamente quando o bloco termina.

9. Trabalhando com caracteres especiais

Para evitar problemas com caracteres como á, é, ç, ã e õ, utilize encoding="utf-8".

with open("mensagem.txt", "w", encoding="utf-8") as arquivo:
    arquivo.write("Programação em Python\n")
    arquivo.write("João está estudando arquivos.")

10. Lendo um arquivo com read()

Crie manualmente um arquivo chamado alunos.txt com este conteúdo:

Ana
Carlos
João
Mariana
Pedro

Agora utilize:

with open("alunos.txt", "r", encoding="utf-8") as arquivo:
    conteudo = arquivo.read()

print(conteudo)

read() lê todo o conteúdo do arquivo de uma vez.

11. Lendo uma linha com readline()

with open("alunos.txt", "r", encoding="utf-8") as arquivo:
    linha = arquivo.readline()

print(linha)

Pergunta

Quantas linhas foram apresentadas?

Agora experimente:

with open("alunos.txt", "r", encoding="utf-8") as arquivo:
    print(arquivo.readline())
    print(arquivo.readline())
    print(arquivo.readline())

readline() lê uma linha por vez.

12. Lendo todas as linhas com readlines()

with open("alunos.txt", "r", encoding="utf-8") as arquivo:
    alunos = arquivo.readlines()

print(alunos)

Resultado aproximado:

['Ana\n', 'Carlos\n', 'João\n', 'Mariana\n', 'Pedro\n']

readlines() retorna uma lista contendo as linhas do arquivo.

13. Lendo o arquivo utilizando for

Uma das formas mais úteis de percorrer um arquivo é usar for:

with open("alunos.txt", "r", encoding="utf-8") as arquivo:
    for linha in arquivo:
        print(linha)

Cada repetição do for lê uma linha.

14. Removendo \n com strip()

with open("alunos.txt", "r", encoding="utf-8") as arquivo:
    for linha in arquivo:
        print(linha.strip())

strip() remove espaços e quebras de linha das extremidades da string.

15. Criando um cadastro simples

nome = input("Digite o nome do aluno: ")

with open("alunos.txt", "a", encoding="utf-8") as arquivo:
    arquivo.write(nome + "\n")

print("Aluno cadastrado!")
  • Execute o programa várias vezes.
  • Cadastre alunos diferentes.
  • Abra alunos.txt e confira se os nomes permaneceram armazenados.

16. Cadastrando vários alunos com while

opcao = "s"

while opcao == "s":
    nome = input("Nome do aluno: ")

    with open("alunos.txt", "a", encoding="utf-8") as arquivo:
        arquivo.write(nome + "\n")

    opcao = input("Cadastrar outro aluno? (s/n): ")

Pergunta

Por que utilizamos "a" e não "w"?

17. Criando um menu

Agora vamos reunir while, match/case e arquivos.

while True:
    print("""
    ===== MENU =====

    1 - Cadastrar aluno
    2 - Listar alunos
    0 - Sair
    """)

    opcao = int(input("Escolha: "))

    match opcao:
        case 1:
            nome = input("Nome: ")

            with open("alunos.txt", "a", encoding="utf-8") as arquivo:
                arquivo.write(nome + "\n")

            print("Aluno cadastrado!")

        case 2:
            with open("alunos.txt", "r", encoding="utf-8") as arquivo:
                for aluno in arquivo:
                    print(aluno.strip())

        case 0:
            print("Programa encerrado.")
            break

        case _:
            print("Opção inválida.")

18. Organizando com funções

def cadastrar_aluno():
    nome = input("Nome: ")

    with open("alunos.txt", "a", encoding="utf-8") as arquivo:
        arquivo.write(nome + "\n")

    print("Aluno cadastrado!")


def listar_alunos():
    with open("alunos.txt", "r", encoding="utf-8") as arquivo:
        for aluno in arquivo:
            print(aluno.strip())

Programa principal:

while True:
    print("""
    1 - Cadastrar
    2 - Listar
    0 - Sair
    """)

    opcao = int(input("Opção: "))

    match opcao:
        case 1:
            cadastrar_aluno()
        case 2:
            listar_alunos()
        case 0:
            break
        case _:
            print("Opção inválida.")

19. Guardando mais de uma informação

Agora queremos armazenar nome e nota.

nome = input("Nome: ")
nota = float(input("Nota: "))

with open("notas.txt", "a", encoding="utf-8") as arquivo:
    arquivo.write(f"{nome};{nota}\n")

O arquivo poderá ficar assim:

Ana;8.5
Carlos;6.0
João;9.0

O caractere ; está sendo usado como separador entre os dados de uma mesma linha.

20. Separando os dados com split()

with open("notas.txt", "r", encoding="utf-8") as arquivo:
    for linha in arquivo:
        dados = linha.strip().split(";")
        print(dados)

Resultado aproximado:

['Ana', '8.5']
['Carlos', '6.0']
['João', '9.0']

split(";") divide a string sempre que encontra ;.

21. Separando diretamente em variáveis

with open("notas.txt", "r", encoding="utf-8") as arquivo:
    for linha in arquivo:
        nome, nota = linha.strip().split(";")

        print("Aluno:", nome)
        print("Nota:", nota)

22. Convertendo os dados

Os dados lidos de um arquivo são inicialmente strings.

nota = float(nota)

Exemplo completo:

with open("notas.txt", "r", encoding="utf-8") as arquivo:
    for linha in arquivo:
        nome, nota = linha.strip().split(";")
        nota = float(nota)

        if nota >= 7:
            situacao = "Aprovado"
        else:
            situacao = "Reprovado"

        print(nome, nota, situacao)

23. Calculando a média das notas

soma = 0
quantidade = 0

with open("notas.txt", "r", encoding="utf-8") as arquivo:
    for linha in arquivo:
        nome, nota = linha.strip().split(";")
        nota = float(nota)

        soma += nota
        quantidade += 1

media = soma / quantidade

print("Média da turma:", media)

24. E se o arquivo não existir?

Experimente:

with open("arquivo_que_nao_existe.txt", "r") as arquivo:
    print(arquivo.read())

Será exibido um erro semelhante a FileNotFoundError.

Podemos tratar esse problema:

try:
    with open("alunos.txt", "r", encoding="utf-8") as arquivo:
        print(arquivo.read())

except FileNotFoundError:
    print("Arquivo não encontrado.")

O tratamento de exceções permite que o programa lide com situações inesperadas sem simplesmente encerrar com erro.

25. Introdução aos arquivos CSV

Arquivos .csv são muito utilizados para armazenar dados organizados em linhas e colunas.

nome;idade;curso
Ana;18;Informática
Carlos;21;Informática
Maria;19;Administração

Eles podem ser abertos em LibreOffice Calc, Microsoft Excel e Google Planilhas. Também podem ser gerados por formulários de pesquisa.

Conexão com o projeto interdisciplinar: os dados coletados por um formulário poderão ser exportados para CSV e processados pelos programas desenvolvidos pela turma.

26. Lendo um CSV com Python

Python possui a biblioteca csv.

import csv

with open("pesquisa.csv", "r", encoding="utf-8") as arquivo:
    leitor = csv.reader(arquivo, delimiter=";")

    for linha in leitor:
        print(linha)

27. CSV com cabeçalho e DictReader

Considere:

nome;idade;curso
Ana;18;Informática
Carlos;21;Informática

Podemos utilizar os nomes das colunas:

import csv

with open("pesquisa.csv", "r", encoding="utf-8") as arquivo:
    leitor = csv.DictReader(arquivo, delimiter=";")

    for pessoa in leitor:
        print("Nome:", pessoa["nome"])
        print("Idade:", pessoa["idade"])
        print("Curso:", pessoa["curso"])

Com DictReader, cada linha pode ser acessada pelos nomes das colunas, o que facilita muito o processamento de formulários.

Resumo rápido

Abrindo arquivos

  • "r" → leitura
  • "w" → escrita/substituição
  • "a" → acrescentar
  • with → fecha automaticamente

Lendo e tratando

  • read() → lê tudo
  • readline() → uma linha
  • readlines() → lista de linhas
  • strip() → remove espaços/quebras
  • split() → separa uma string

Ideia principal:

Variáveis mantêm dados durante a execução.

Arquivos permitem que os dados continuem existindo depois que o programa termina.
